# brandgulp/.github

> Organization-wide community health files for the
> [brandgulp](https://github.com/brandgulp) organization.

BrandGulp is a private commercial product. This repository is public **only** so
that the health-file cascade works and the org page is not a bare listing; it
carries no source and no product documentation.

There is deliberately **no `profile/README.md`** here. The org has no public
repositories, and `brandgulp.com` was not serving when this was written
(HTTPS failed, HTTP returned 502), so there is no honest outbound link for a
profile to point at. Add the profile when one of those two facts changes — see
`orgs/OPERATING-BIBLE.md`, tier model.
